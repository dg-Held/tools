# Heizlast – Methodik und Abgrenzung

Das Heizlast-Tool ist eine eigenständige Beratungsoberfläche. Es verwendet die
gemeinsamen Klimadaten automatisch, ohne dass das Klima-Tool vorher geöffnet
werden muss.

Aktuelle Methoden:

- verbrauchsbasierte Heizlastorientierung,
- flächenbezogener Plausibilitätskorridor,
- optionaler Vergleich mit unabhängigem HWB und BGF,
- Vergleich mit installierter Minimal- und Maximalleistung.

Die Berechnung ersetzt keine Norm-Heizlast. Später kann eine bauteilbasierte
Abschätzung auf Basis derselben Gebäudehülle ergänzt werden, die auch
Energiefluss V4 verwendet.
