# Installation – Bauteil & Sanierung V0.3

1. Website-Hauptordner sichern.
2. ZIP entpacken.
3. Den Inhalt des Paketordners über den Website-Hauptordner kopieren.
4. Gleichnamige Dateien ersetzen.
5. `pages/tools.html` und `tools/bauteil-sanierung/index.html` mit Strg+F5 neu laden.

## Einmalig manuell löschen

Nach erfolgreichem Test kann die alte Datei gelöscht werden:

`shared/data/costs/lifetimes.json`

V0.3 lädt die Nutzungsdauern stattdessen aus:

`shared/data/standards/economics/component-lifetimes.json`

Keine großen Klima-, Adress- oder OIB-Datenordner werden ersetzt.
