# Installation – Finalisierungspaket V0.5

1. Aktuellen Website-Hauptordner sichern.
2. ZIP entpacken.
3. Den Inhalt des entpackten Paketordners über den Website-Hauptordner kopieren.
4. Gleichnamige Dateien ersetzen lassen.
5. Mit `Strg + F5` neu laden:
   - Standortpass,
   - Energiefluss V4,
   - Bauteil & Sanierung,
   - Toolübersicht.
6. Testplan durchführen.

Es muss nichts verschoben oder gelöscht werden.

Eigene Haustürgrafiken können optional unter folgenden Namen ergänzt werden:

```text
assets/svg/tools/bauteil-sanierung/bestand-aussentuer.svg
assets/svg/tools/bauteil-sanierung/sanierung-aussentuer.svg
```
