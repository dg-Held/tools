# Installation – Bauteil & Sanierung V0.1

1. Sicherheitskopie des Website-Hauptordners erstellen.
2. Inhalt des Änderungspakets über den Website-Hauptordner kopieren.
3. Gleichnamige Dateien ersetzen.
4. `pages/tools.html` mit Strg + F5 neu laden.
5. Neues Tool unter `tools/bauteil-sanierung/index.html` öffnen.

Es müssen keine großen Klima-, Adress- oder OIB-Dateien verschoben werden.

Der alte V3-Ordner `tools/energiefluss/` ist im Paket nicht enthalten. Wurde der Link bereits auf V4 umgestellt und V3 extern archiviert, kann er auf der Website gelöscht bleiben.
