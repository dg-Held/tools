# Gemeinsame Klimadaten

Die großen INCA-Daten liegen unter `inca/` und werden von den getrennten Tools
Klima und Heizlast gemeinsam verwendet. Sie sind wegen ihrer Größe nicht in
jedem Änderungspaket enthalten.

Neue vollständige Jahre werden mit
`tools/klima/tools/INCA_JAHR_AUFBEREITEN.bat` ergänzt.
