# Optionale SVG-Grafiken – Bauteil & Sanierung

Eigene Grafiken sind optional. Wenn eine Datei fehlt, zeigt das Tool automatisch eine integrierte Fallback-Grafik.

## Gestaltungsprinzip

- möglichst quadratisch oder leicht hochformatig,
- transparente Fläche möglich,
- keine Texte notwendig,
- Bestand und Sanierung als zusammengehöriges Paar gestalten,
- SVG ohne externe Schrift- oder Bilddateien speichern.

## Dateinamen

bestand-aussenwand.svg
